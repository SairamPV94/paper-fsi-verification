# collapsibleChannel: same-lineage cross-code check (FEniCSx, monolithic ALE)

Status: **draft supplementary evidence. A cross-code check by the same research group and tooling lineage as the reference runs; not an independent validation, not externally reviewed. The solver repository is private and the raw run output is not yet public: this package does not allow the study to be reproduced from the PR alone (only the derived tables and figures can be regenerated from the input CSVs, see below) until an archived snapshot exists.**

Related collapsibleChannel work in the paper: PR #30 (FEBio audit, open draft), PR #45 (strict-tolerance sweeps, merged), PR #51 (mesh-study figure and the solids4foam F1-F4 data, merged), `paper-data/benchmark_inventory.md`.

## Comparison with the spatially extrapolated oomph-lib solution (added after the review of this PR; supersedes the old-reference statements below)
The authors' refinement study (PR #74; `../collapsible_mesh_study/oomph_refine{1..4}_dt160.csv`, `oomph_extrapolated_dt160.csv` = 4 f4 - 3 f3) shows first-order spatial convergence of oomph-lib and a refine-1 (tutorial) spatial error of 0.53 % of the peak (history L-inf, x = 10; reproduced here: 0.528, `history_norms_vs_extrapolated_oomph.csv`) and +0.19 % P at the first trough (x = 10; +0.125, +0.133 at the quarter points). Our earlier "0.26 % oomph spatial bias" (a refine 1 against 2 history L-inf estimate at dt 0.025, sign unknown) is superseded. The extrapolated file exists at dt 0.00625 only (240 steps, same time grid as our cells), so only the dt 0.00625 cells (S1, S2, S3) could be compared; the dt 0.0125 and 0.003125 cells and Table S3 (successive differences, refine-1 same-dt references) could not be redone and are labelled as against the tutorial reference. Everything below is analysis only (no simulation).
- First trough (percent of P), FE minus extrapolated oomph, x = 7.5 / 10 / 12.5: S3 bottom +0.035 / +0.020 / +0.033; S3 midplane +0.013 / +0.012 / +0.010; S2 bottom +0.061 / +0.038 / +0.058; S2 midplane +0.038 / +0.030 / +0.035; S1 bottom +0.047 / -0.002 / +0.066 (S1 is non-monotone with S2, S3). FE is shallower than the extrapolated solution by 0.01-0.06 % P at every point except S1 at x = 10. For comparison, old offsets (FE S3 bottom minus refine-1 oomph at dt 0.00625): -0.090 / -0.173 / -0.100; refine-1 minus extrapolated +0.125 / +0.192 / +0.133. solids4foam F1-F4 at x = 10: +0.227 / +0.107 / +0.046 / +0.020 (the values stated in PR #74 are reproduced).
- History L-inf (t <= 1.5 s) against the extrapolated oomph: FE S3 bottom 0.065 / 0.075 / 0.069 (x = 7.5 / 10 / 12.5; midplane 0.055 / 0.072 / 0.056), S2 0.096 / 0.105 / 0.095, S1 0.76 / 1.09 / 0.80; solids4foam F4 (x = 10) 0.33 (0.22 for t <= 1.25; the 0.334 of PR #74 reproduced); oomph refine 1-4 at x = 10: 0.53 / 0.24 / 0.16 / 0.12 (the values of PR #74 reproduced).

### Hypotheses (registered outcomes; details)
- **H1** (spatial): predicted trough changes 0.5-3 % P (S1 to S2) and 0.1-0.5 % P (S2 to S3), falsifier non-monotone V1: falsified. V1 is non-monotone in space at x = 7.5 and 10 at every dt, and the differences grow at x = 12.5; `convergence_analyse.csv` rejects every spatial series; no spatial order or limit.
